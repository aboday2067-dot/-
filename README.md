# NovaLearn AI — V1 preview (web app)

تطبيق ويب تفاعلي مبني على وثيقة **NovaLearn AI Design System v1.0**. بدون أي مكتبات أو خطوات بناء: HTML + CSS + JavaScript عادي، يعمل بفتح `index.html` أو عبر GitHub Pages.

An interactive web app built from the **NovaLearn AI Design System v1.0**. No dependencies and no build step: plain HTML, CSS and JavaScript.

## تشغيل / Run
- محليًا: افتح `index.html` في المتصفح، أو `python3 -m http.server` ثم `http://localhost:8000`.
- GitHub Pages: ارفع المشروع إلى فرع `main`، ثم من *Settings → Pages* اختر **Source: GitHub Actions**. ملف `.github/workflows/pages.yml` ينشر تلقائيًا.

## الصفحات / Pages
تسجيل الدخول وإنشاء حساب · لوحة المتعلم (قابلة للتخصيص) · المسارات والمقررات · الدروس · التقييم النظري · مختبرات الممارسة · جواز المهارات · المجتمع · الإشعارات · الإعدادات والتخصيص · المزامنة والتخزين · الإدارة (3 تبويبات) · صفحة نظام التصميم · رفيق نوفا (لوحة عائمة).

## ما الذي يغطيه من الوثيقة
- عربي RTL وإنجليزي LTR مع تبديل فوري دون فقدان السياق، نصوص مركزية في `js/strings.js`.
- سمات فاتحة/داكنة/تلقائية، ألوان تمييز، كثافة، حجم نص، تقليل الحركة، وضع البيانات المنخفضة، إعادة الضبط.
- تنقل: شريط جانبي قابل للطي، شريط سفلي ودرج للجوال، فتات التنقل.
- عمل دون اتصال: حفظ محلي، طابور مزامنة دائم، ترتيب العمليات، معرّفات فريدة (عدم التكرار)، إعادة محاولة بتأخير، حالات الاتصال الصادقة.
- نتائج الاختبارات والمختبرات **مؤقتة** إلى أن "يقبلها الخادم"، والمهارة الموثقة تتطلب الدروس + النظري + مختبر ناجح، وكلها بقبول الخادم.
- إمكانية الوصول: تركيز مرئي، قارئ شاشة، أهداف لمس 44px، حوارات بمصيدة تركيز، فحص تباين حي في صفحة نظام التصميم.

## حدود هذه النسخة (مهم)
1. **لا يوجد خادم حقيقي.** "الخادم" في `js/engine.js` محاكاة محلية لإثبات القواعد. بيانات المستخدم في `localStorage` وغير مشفّرة.
2. **المصادقة تجريبية:** الحسابات في المتصفح فقط. الإصدار الحقيقي يحتاج مصادقة وصلاحيات على الخادم (الوثيقة 22.4).
3. **رفيق نوفا ردوده بقواعد ثابتة** وليس نموذج ذكاء اصطناعي. الصوت يطلب إذن الميكروفون فقط ولا يعالج كلامًا.
4. **المختبرات تفحص النص بأنماط** ولا تشغّل الشيفرة.
5. المحتوى التعليمي عينات (`js/data.js`). قيم الألوان والأحجام "قيم عمل" ما زالت **Needs Validation** كما في الوثيقة.
6. الشهادات والخريطة الذهنية وتحدي الأقران ومعالجة الصوت غير مضمّنة (خارطة الطريق).
7. الترجمة العربية تحتاج مراجعة لغوية معتمدة، والإنجليزية هي المرجع.

## الخطوات التالية المقترحة
خادم (Auth + API + قاعدة بيانات) يستبدل `serverApply` · نموذج ذكاء اصطناعي لرفيق نوفا · تشغيل آمن للشيفرة في المختبرات · محتوى حقيقي · اختبار يدوي وبقارئ الشاشة · تدقيق التباين على أجهزة حقيقية.

